# Product

## Register

product

## Users

syncFile serves people moving files between their own computers or trusted peers on the same local network. They are usually in a task already: sending a file quickly, accepting an incoming file, checking whether a device is reachable, or finding where a received file landed.

## Product Purpose

syncFile is a cross-platform LAN file transfer tool with an AirDrop-like goal: open the app, discover nearby devices automatically, drop files, and complete the transfer without accounts, IP entry, or server setup.

Success means the core path is obvious at a glance: discover devices, choose recipients, add files, send, and inspect transfer results. The interface should make security state and transfer state clear without forcing users through configuration before the first successful transfer.

## Brand Personality

Quiet, capable, trustworthy.

The product should feel native to desktop workflows: calm enough for repeated daily use, precise enough for transfer and trust decisions, and lightweight enough that the UI does not feel heavier than the file move itself.

## Anti-references

Avoid marketing-style SaaS dashboards, decorative network graphics, neon cyber themes, heavy glassmorphism, and generic card grids. Avoid UI that makes local network transfer feel like a cloud service or an admin console.

## Design Principles

1. Lead with the transfer path: device discovery, file staging, send readiness, and transfer results should form one continuous workflow.
2. Make state legible: online, trusted, selected, blocked, pending, active, failed, and completed states need distinct but restrained treatment.
3. Keep advanced controls secondary: settings, logs, sandbox maintenance, and trust management should be accessible without competing with the send flow.
4. Prefer desktop familiarity: use predictable navigation, buttons, segmented controls, lists, and panels instead of novelty controls.
5. Earn density through hierarchy: compact information is acceptable when headings, grouping, and spacing make the next action obvious.

## Accessibility & Inclusion

Target WCAG AA contrast for text and controls. Preserve keyboard focus visibility, avoid relying on color alone for transfer or trust state, and respect reduced-motion preferences for non-essential transitions.
